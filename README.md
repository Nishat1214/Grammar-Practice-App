# Grammar-Practice-App

An interactive web app that helps users practice English grammar with a real-time scoring system.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript

## ✨ Features
- Multiple-choice grammar questions
- Real-time scoring system
- User-friendly interface

## 🚀 How to Run
1. Clone this repository
2. Open `index.html` in your browser
3. Start practicing!
